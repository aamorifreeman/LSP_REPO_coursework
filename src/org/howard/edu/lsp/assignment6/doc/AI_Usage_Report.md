
# AI Usage Report

For Assignment 6, I used **Claude Chat** to better understand the assignment requirements, ask clarifying questions, and develop a plan for implementing the required tests. Once I had established the plan, I used **OpenAI Codex** to implement it.

Codex generated the JUnit test cases using the instructor's provided template, compiled the code, and ran the test suite using JDK 17 and JUnit 5. All 47 tests passed. I also used Codex to integrate the completed files into my course repository, verify that the test method names matched the instructor's template, and rerun the tests.

The Assignment 5 implementation was reused without modification, aside from the package declaration. Any AI assistance used for that implementation is documented separately in my Assignment 5 AI Usage Report.
